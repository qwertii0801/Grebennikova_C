Bвод-вывод и работа с файлами в языке C
Цель работы
Освоить работу с файлами: открытие и закрытие потоков, чтение и запись текстовых и бинарных данных, форматированный ввод-вывод, перемещение по файлу.

Используемые инструменты
В ходе выполнения лабораторной работы использовался язык программирования C. Для работы с файлами применялась библиотека stdio.h, которая содержит функции fopen, fclose, putc, getc, fputs, fgets, fprintf, fscanf, fwrite, fread, fseek, ftell, feof, ferror. Для компиляции программ использовался компилятор GCC. Для написания кода использовалась любая среда разработки или текстовый редактор, поддерживающая язык C.


В результате выполнения лабораторной работы удалось освоить следующие навыки и знания:

Открытие и закрытие файлов с помощью функций fopen и fclose. Научился проверять успешность открытия файла, так как при ошибке fopen возвращает NULL. Понял важность закрытия файла после завершения работы с ним.

Различные режимы открытия файлов: r для чтения, w для записи с перезаписью, a для дозаписи в конец файла, а также бинарные режимы rb и wb.

Посимвольную запись и чтение файла с помощью функций putc и getc. Это позволяет обрабатывать файл по одному символу.

Запись и чтение строк с помощью fputs и fgets. Функция fgets безопаснее чем scanf, так как позволяет ограничить количество считываемых символов.

Форматированный ввод-вывод в файл с помощью fprintf и fscanf. Эти функции работают с файлом так же как printf и scanf работают с экраном и клавиатурой.

Ввод строки с клавиатуры с помощью fgets и запись её в файл.

Работу с бинарными файлами. Отличие текстовых файлов от бинарных в том, что текстовые хранят данные в читаемом виде, а бинарные хранят данные в том же виде, что и в памяти.

Запись и чтение массивов с помощью fwrite и fread. Эти функции позволяют записывать блоки данных любого размера напрямую в файл и считывать их обратно.

Работу со структурами в бинарных файлах. Научился записывать структуру целиком в файл и считывать её обратно. Также освоил запись и чтение массива структур.

Позиционирование в файле с помощью функции fseek. Это позволяет перемещаться к любой позиции в файле и начинать чтение с нужного места.

Определение размера файла с помощью комбинации fseek и ftell. Сначала перемещаю указатель в конец файла, затем с помощью ftell получаю текущую позицию которая и является размером файла.

Проверку конца файла с помощью feof и проверку ошибок с помощью ferror. Это помогает корректно обрабатывать чтение до конца файла и выявлять проблемы при работе с файлами.

Создание простой файловой базы данных. Научился вводить данные с клавиатуры, записывать их в бинарный файл, считывать все записи из файла и выводить на экран.

Вывод
В ходе выполнения лабораторной работы были полностью освоены все основные аспекты работы с файлами в языке C. Полученные навыки позволяют создавать программы которые могут сохранять данные на диск, читать их обратно, обрабатывать текстовые и бинарные файлы, а также создавать простые файловые базы данных. Эти знания являются важными для разработки реальных приложений которые работают с постоянным хранением информации.
