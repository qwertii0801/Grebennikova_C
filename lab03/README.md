Динамические массивы в языке C
Цель работы
Изучить работу с динамической памятью: функции malloc, calloc, realloc, free, создание и использование динамических массивов.

Используемые инструменты
В ходе выполнения лабораторной работы использовался язык программирования C. Для работы с динамической памятью применялась библиотека stdlib.h, которая содержит функции malloc, calloc, realloc и free. Для ввода и вывода данных использовалась библиотека stdio.h. Компиляция программ осуществлялась с помощью компилятора GCC. Для написания кода использовалась любая среда разработки или текстовый редактор, поддерживающая язык C.

В результате выполнения лабораторной работы удалось освоить следующие навыки и знания:

Выделение динамической памяти с помощью функции malloc. Этот навык позволяет создавать массивы размер которых заранее неизвестен и задается пользователем во время работы программы.

Использование функции calloc которая не только выделяет память но и автоматически обнуляет все элементы массива. Это удобно когда нужно гарантированно получить массив заполненный нулями.

Изменение размера уже существующего динамического массива с помощью функции realloc. Это позволяет увеличивать или уменьшать массив во время работы программы без потери уже имеющихся данных.

Освобождение динамической памяти с помощью функции free. Это критически важный навык позволяющий избегать утечек памяти когда программа потребляет ресурсы но не возвращает их обратно системе.

Правильную проверку возвращаемого значения функций выделения памяти на NULL. Это помогает обрабатывать ситуации когда системе не хватает памяти для выделения запрошенного блока.

Написание функций для поиска максимального и минимального элементов в массиве а также для вычисления суммы всех элементов.

Реализацию удаления элемента из динамического массива по индексу со сдвигом оставшихся элементов и последующим уменьшением размера массива.

Реализацию вставки нового элемента в заданную позицию со сдвигом элементов вправо и увеличением размера массива.

Создание динамического массива структур на примере структуры Student содержащей имя и возраст. Также был освоен поиск элемента в таком массиве по заданному критерию.

Разработку полноценного динамического списка с меню позволяющего добавлять элементы удалять элементы выводить список и изменять размер массива в интерактивном режиме.

Создание меню без использования условных операторов if else и switch case с помощью массива указателей на функции что является более продвинутым подходом.

Понимание разницы между статическими и динамическими массивами а также осознание важности ручного управления памятью в языке C.

Вывод
В ходе выполнения лабораторной работы были полностью освоены все основные аспекты работы с динамической памятью в языке C. Полученные навыки являются фундаментальными для написания эффективных программ которые работают с данными неизвестного объема и требуют гибкого управления ресурсами памяти.
